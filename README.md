# Grocify
A platform to compare product prices across stores, suggest the least expensive items, and reduce food waste.

## Features
- Price comparison
- Item Recommendaion
- Smart shopping list
- Shop Prediction

## Prerequisites
- Git Installed
- Node.js Installed
- MongoDB Installed and Running

## Installation & Setup
### Clone Repository

```console
git clone https://github.com/Nish245/Grocify.git
```

## Environment / Database Setup

### Install Dependencies

```console
npm install
```

### Start Server

```console
npm run start
```
### Access application at
http://localhost:3000
