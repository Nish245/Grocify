Pre-Trained Model:

The k-NN model (item_recommendation_knn_model.joblib) is pre-trained and saved. It can be directly loaded without retraining.
Feature Matrix:

The feature_matrix.npy is the exact representation of your product features, used for recommendation queries.
The matrix is lightweight and efficient for querying similarity.
Python Script (recommendation.py):

This script is built to:
Load the model and matrix.
Take user input (product index and number of recommendations).
Return recommendations in JSON format, which can be consumed by your Node.js backend.
Node.js Integration:

The Python script is called from Node.js using child_process.
The output is parsed and returned to the frontend, ensuring seamless integration.
